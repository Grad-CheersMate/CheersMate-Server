## 🏗 **프로젝트 구조**
```
Stargram
│── src
│   ├── main
│   │   ├── java/com/
│   │   │   ├── config         # 프로젝트 설정 (예외 처리, 보안, 키 관리 등)
│   │   │   ├── controller     # REST API 컨트롤러
│   │   │   ├── domain         # 비즈니스 로직
│   │   │   ├── entity         # DB 엔티티 및 DTO
│   │   │   ├── repository     # 데이터 접근 계층
│   │   │   ├── service        # 서비스 계층 (비즈니스 로직 처리)
│   │   ├── resources
│   │   │   ├── application.yml  # 환경 설정 파일
│   ├── test                   # JUnit 기반 테스트 코드
│── build.gradle               # 프로젝트 의존성 관리
```
